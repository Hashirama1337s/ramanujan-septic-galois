## In plain words
- **The question.** v3c proved: when 2 "goes all the way round" the symmetry group of Q(zeta_p)^+, the conjugates of the norm N of Ramanujan's
  unit b_1 sit inside the cyclotomic units C' with index 2^(m-1) p^(m-2) h^-/h(-p). At p = 31, 127, 151, 223 the prime 2 only goes part of the
  way round (order f = 5, 7, 15, 37 instead of m). What happens then?
- **Answer, proved on the page.** The conjugates of N lose exactly m/f - 1 directions (rank m - m/f). They fill a clean sub-box of C': the units
  whose norm down to the subfield fixed by sigma_2 is +-1, which is also the span of the conjugates of the single Hasse unit xi_2. Inside that
  sub-box their index is the same Bernoulli product as before, but taken only over the characters with chi(2) != 1:
  **[S : X] = prod_{chi(2) != 1} p|B_{1,chi psi}|.**
- **The p-th roots (w-units) remove the p-power exactly.** Adding the norms of v3b's w-units w_k = u_1^(k^2)/u_k divides the index by exactly
  p^(r-1): [S : W] = [S : X]/p^(r-1). At 31 this leaves 2^12; at 23 it leaves 2^10; at 7 it leaves 4 (the v3b value).
- **The test.** Analytic conjugates of b_1 at 150-500 digits, exponent vectors rounded, then exact integer lattice algebra, at 7 primes
  (3 controls where 2 generates, 4 where it does not). Every sealed prediction HOLDS; every null behaves. One descriptive clause in the bar
  (S = {sigma_2(u)/u}) was wrong on paper; it was not part of the run; corrected below (that set has index f in S).
- **The guess in the brief is off by an explicit factor.** "Product of |A_chi/C_chi| over chi(2) != 1" is not the index; it equals
  [S : X] f^(m/f)/2^r (checked exactly at 31, 127, 151, 223).
- **Ceiling.** Lemma level: a clean generalisation of v3c Corollary 2 by group-ring algebra. Not a new kind of result.

## 1. Statement
Setting as in ../../veins/v3c/RESULT-V3C.md. p = 7 mod 8 prime, m = (p-1)/2, G = (Z/p)*/{+-1} = Gal(Q(zeta_p)^+/Q), sigma_c : zeta -> zeta^c.

H := <sigma_2>, N_H := sum_{h in H} h. psi = (./p). chi runs over the even characters mod p (= characters of G).
xi_a := (zeta^{a/2} - zeta^{-a/2})/(zeta^{1/2} - zeta^{-1/2}) (branch zeta^{x/2} := zeta^{x(p+1)/2}), C' := <-1, xi_2, ..., xi_m>, bar = mod {+-1}.

W := subgroup generated by the G-conjugates of Nbar and of N(w_k)bar, k = 2..m. S := (X (x) Q) ∩ C'bar (saturation of X in C'bar). r := m - m/f.

**Theorem I1.** For every prime p = 7 mod 8:
(a) rank X = r = m - m/f; the drop m/f - 1 is #{chi != 1 : chi(2) = 1}.
(b) S is the subgroup generated by the G-conjugates of xi_2, and S = {u in C'bar : prod_{h in H} h(u) = 1}, i.e. the units of C' whose norm to the
    fixed field of sigma_2 in Q(zeta_p)^+ (degree m/f) is +-1.
(c) **[S : X] = prod_{chi even, chi(2) != 1} p |B_{1, chi psi}|.**
(d) Every N(w_k) lies in C' (explicitly N(w_k) = +- phi(y_k), y_k below). rank W = r, the saturation of W is S, and
    **[S : W] = [S : X] / p^{r-1} = prod_{chi(2) != 1} p|B_{1,chi psi}| / p^{r-1}.**
When f = m this is v3c Corollary 2 (S = C'bar, [S : X] = 2^{m-1} p^{m-2} h^-/h(-p)), plus the new w-statement [C'bar : W] = 2^{m-1} h^-/h(-p).

**Lemma 1 (cyclic norm kernel).** Lambda := (sigma_2 - 1) Z[G] equals ker(N_H : Z[G] -> Z[G]); it lies in I_G; Lambda (x) C = sum of the lines
C e_chi with chi(2) != 1; rank Lambda = m - m/f.
*Proof.* Z[G] is a free Z[H]-module on coset representatives g_1..g_{m/f}: x = sum_i y_i g_i, y_i in Z[H]. In Z[H], N_H h = N_H for h in H, so
N_H y = aug(y) N_H, and N_H x = sum_i aug(y_i) N_H g_i, which is 0 iff every aug(y_i) = 0. In the cyclic group H = <sigma_2>,
{y : aug(y) = 0} = I_H = (sigma_2 - 1) Z[H], because sigma_2^k - 1 = (sigma_2 - 1)(1 + sigma_2 + ... + sigma_2^{k-1}). Hence
ker N_H = sum_i (sigma_2 - 1) Z[H] g_i = (sigma_2 - 1) Z[G]. aug((sigma_2 - 1)x) = 0, so Lambda is in I_G. On e_chi, N_H acts by
sum_{h in H} chi(h) = f if chi(2) = 1, else 0; so Lambda (x) C = ker N_H (x) C = sum_{chi(2) != 1} C e_chi. Characters with chi(2) = 1 are the
characters of G/H: m/f of them, including chi = 1. ∎

**Lemma 2 (index of beta).** [Lambda : beta Lambda] = prod_{chi(2) != 1} |chi(beta)| = prod_{chi(2) != 1} p|B_{1,chi psi}|.
*Proof.* Lambda is a Z[G]-module, so beta Lambda ⊂ Lambda. beta acts on Lambda (x) C diagonally in the basis e_chi (chi(2) != 1) with eigenvalues
chi(beta) != 0 (V3), so beta is injective on Lambda and [Lambda : beta Lambda] = |det(beta | Lambda (x) Q)| (an injective endomorphism of a free
Z-module of finite rank has index |det|, by Smith normal form) = prod_{chi(2) != 1} |chi(beta)| = prod p|B_{1,chibar psi}|. chi -> chibar permutes
{chi : chi(2) != 1}. ∎

**Proof of (a)-(c).** By (V2), X = phi(Z[G] theta) = phi(beta Lambda), since sigma_{1/4} is a unit of Z[G] and Z[G] is commutative.
X (x) Q = phi(Lambda (x) Q) because beta is invertible on Lambda (x) Q (Lemma 2), so rank X = rank Lambda = r (Lemma 1): (a).
Through the isomorphism (V1), S corresponds to (Lambda (x) Q) ∩ I_G = (Lambda (x) Q) ∩ Z[G]. If x in Z[G] and n x in Lambda for some n >= 1,
then n N_H x = 0, so N_H x = 0 and x in Lambda (Lemma 1). Hence **S = phi(Lambda)**, the Z[G]-span of phi(sigma_2 - 1) = xi_2, and
phi(Lambda) = phi(ker N_H ∩ I_G) = {u in C'bar : N_H u = 1}: (b). Finally [S : X] = [Lambda : beta Lambda] (phi is an isomorphism): (c) by Lemma 2. ∎

**Lemma 3 (the p-congruence).** For every integer k prime to p, (k^2 - sigma_{k^2}) beta is in p Z[G].
*Proof.* Define s : G -> F_p*, s(+-x) := x (x/p); it is well defined because (-1/p) = -1, and it is a homomorphism. For b in 1..m,
(b/p) b = s(b) = s(g)^{-1} with g := class of 1/b. Since p - 2b = -2b mod p, beta = -2 e (mod p) with e := sum_g s(g)^{-1} g (g = sigma_{1/b}
runs over G as b runs over 1..m). Then sigma_c e = sum_g s(g)^{-1} sigma_{cg} = s(c) e (substitute g' = cg). For c = k^2, s(c) = k^2 (a square),
so (k^2 - sigma_{k^2}) e = 0 in F_p[G]. ∎

**Proof of (d).** *Norms.* M = F_p(zeta_p), F_p ∩ Q(zeta_p) = Q(zeta_p)^+, so restriction Gal(M/Q(zeta_p)) -> Gal(F_p/Q(zeta_p)^+) is a bijection on
embeddings and N_{F_p/Q(zeta_p)^+} = N_{M/Q(zeta_p)} on F_p (as in v3c §1). Gal(M/Q(zeta_p)) lies in the abelian group Gal(M/K) (K ⊂ Q(zeta_p)
since p = 3 mod 4), so N(sigma_k x) = sigma_k N(x) for x in F_p, and sigma_k acts on Q(zeta_p) as sigma_{k^2} (V4). From w_k^p = b_1^{k^2}/b_k and
b_k = sigma_k(b_1): **N(w_k)^p = N^{k^2} / sigma_{k^2}(N)**, so p l(N(w_k)) = k^2 l(N) - sigma_{k^2} l(N).
*Membership.* Put y_k := p^{-1}(k^2 - sigma_{k^2}) theta. By Lemma 3, y_k is in Z[G]; aug(y_k) = 0, so y_k is in I_G. Then
p l(phi(y_k)) = l(phi(p y_k)) = k^2 l(N) - sigma_{k^2} l(N) = p l(N(w_k)). Two units of Q(zeta_p)^+ with the same l agree up to sign:
**N(w_k) = +- phi(y_k) ∈ C'.**
*The module.* Let A := ker(s~ : Z[G] -> F_p, g -> s(g)), an ideal of index p. A' := (p, k^2 - sigma_{k^2} : k = 2..m) ⊂ A. Every class in G
contains exactly one square, and the squares mod p are the k^2, k = 1..m; so every g is congruent mod A' to an integer, Z[G]/A' is cyclic of
order <= p, and A' = A. Hence W = phi(Z[G] theta + sum_k Z[G] y_k) = phi(p^{-1} A Y), Y := Z[G] theta (so X = phi(Y)). W ⊂ S since
W (x) Q = X (x) Q and W ⊂ C'bar; so rank W = r and the saturation of W is S.
*[W : X] = p^{r-1}.* [p^{-1} A Y : Y] = [A Y : p Y] = p^r / [Y : A Y]. Y/AY is killed by p, so it equals Y_p/A Y_p with Y_p := Y (x) Z_p. Since
m | p - 1 and p ∤ m, Z_p[G] = prod_chi Z_p e_chi (characters with values in mu_m ⊂ Z_p*), and Y_p = sum_chi chi(theta) Z_p e_chi with
chi(theta) = chi(1/4) chi(beta)(chi(2) - 1), non-zero exactly for chi(2) != 1 (the same algebraic number as over C). A acts on the chi-line
through the ideal chi(A) ⊂ Z_p (chi extended Z_p-linearly to Z_p[G]); since A is generated by p and the g - s~(g) (s~(g) an integer lift of s(g)),
chi(A) is the ideal generated by p and the chi(g) - s~(g), g in G.
**(v2, referee fix) Computation of chi(A).** (i) If chi(g) = s(g) mod p for every g, then for x = sum_g x_g g in A,
chi(x) = sum_g x_g chi(g) = sum_g x_g s(g) = s~(x) = 0 mod p, so chi(A) ⊂ pZ_p; and p in A gives chi(A) ⊃ pZ_p. Hence **chi(A) = (p)**.
The reduction mu_m -> F_p* is injective (p ∤ m), so the condition "chi(g) = s(g) mod p for all g" holds for exactly one character of G,
the Teichmüller lift omega_s of s (omega_s(g) := the root of unity in mu_m reducing to s(g); it is a character because s is).
(ii) If chi != omega_s, then chi(g) and omega_s(g) are distinct elements of mu_m for some g, so chi(g) - s~(g) = chi(g) - omega_s(g) (mod p)
is a p-adic unit (distinct m-th roots of unity stay distinct mod p); hence **chi(A) = Z_p**.
Consequently, line by line: for chi != omega_s with chi(2) != 1, A Y_p ∩ (chi-line) = the whole chi-line; on the omega_s-line it is p times
that line. omega_s(2) = s(2) = 2 != 1 mod p, so omega_s(theta) != 0 (V3; a non-zero algebraic number stays non-zero under a field embedding into
Q_p), the omega_s-line of Y_p is a non-zero free Z_p-module of rank 1, and Y_p/AY_p = Z_p/pZ_p = Z/p, whatever the p-adic valuation of
omega_s(theta). Hence [Y : AY] = p and [W : X] = p^{r-1}, so [S : W] = [S : X]/p^{r-1}: p^{-1}A leaves the omega_s-line unchanged and
enlarges each of the other r - 1 lines by p. ∎
