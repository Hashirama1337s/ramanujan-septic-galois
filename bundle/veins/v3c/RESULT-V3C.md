**Theorem V3C.** For every even chi != 1 mod p:
  **A_chi = (p/2) · chi(2) (chi(2) - 1) · B_{1, chi psi} · C_chi = -p · chi(2) (1 - chi(2)) · L_K'(0, chi o N_{K/Q}),**
where L_K(s, chi o N) = L(s, chi) L(s, chi psi), L'(0, chi) = -C_chi/2 and L(0, chi psi) = -B_{1,chi psi}.
Absolute values give the v3b statement |A_chi| = (p/2)|1 - chi(2)||B_{1,chi psi}||C_chi|. Since L(1, chi) and L(1, chi psi) are non-zero,
A_chi = 0 **iff chi(2) = 1** (the 2 zeros at p = 31 and the 8 sealed zeros at p = 127).

**Corollary 1 (the norm itself).** Let xi := zeta^{(p+1)/2} + zeta^{-(p+1)/2} in Q(zeta_p)^+ (xi^2 = (1-zeta^2)(1-zeta^-2)/((1-zeta)(1-zeta^-1))),
sigma_c : zeta -> zeta^c. Then
  **N_{F_p/Q(zeta_p)^+}(b_1) = +- prod_{b=1}^{m} sigma_{(4b)^{-1}}(xi)^{ (b/p)(p - 2b) }**   (inverses mod p).
Equivalently N^2 = prod_b (eta_{(4b)^-1}/eta_{(2b)^-1})^{(b/p)(2b-p)}, eta_c = (1-zeta^c)(1-zeta^-c). At p = 7 this is b_1 = s3^6 s1^-4 s2^-2
(s_j = sin(j pi/7)), the known u_1^7 = d2^6/d1^2 with d_j = sin((j+1)pi/7)/sin(pi/7).
*Proof.* Write (p/2)B_{1,chi psi} = sum_{b=1}^m chi(b) (b/p)(2b - p)/2 (pair b with p - b; chi psi is odd), so the multiplier of Theorem V3C is
lambda(chi) = (chi(4) - chi(2)) sum_b chi(b)(b/p)(2b-p)/2 = sum_c chi(c) Theta(c) for an explicit Theta in (1/2)Z[G+]. Then log|iota_a(N)| and
the logarithm of the right side have the same chi-component for every chi != 1. For chi = 1 both components are 0: N is a unit, and the right
side is a product of units (augmentation of Theta is lambda(1) = 0). Two elements of the totally real field Q(zeta_p)^+ with equal absolute
values in every embedding agree up to sign. ∎

The terms of V that do not depend on u (log 2 and the w-term) drop out, since sum_u chi^2(u) = 0 (chi^2 != 1: there is no even quadratic
character mod p = 3 mod 4).

**Step 3 (Kronecker's second limit formula).** For a lattice L of covolume A(L) and z not in L, let
E(z, L; s) := sum'_{omega in L} e( Im(conj(z) omega)/A(L) ) (A(L)/|omega|^2)^s  (Re s > 1; entire continuation). Then
  **E(z, L; 1) = -2 pi log|g(z; L)|.**
With L = Z tau + Z, omega = m tau + n, z = r1 tau + r2 this is E_{u,v}(tau, s) = sum' e(mu + nv) y^s/|m tau + n|^{2s} with (u, v) = (r2, -r1),
and the Wikipedia statement (OPENED: "E_{u,v}(tau,1) = -2 pi log|f(u - v tau; tau) q^{v^2/2}|", f(z, tau) = q^{1/12}(p^{1/2} - p^{-1/2})
prod (1 - q^n p)(1 - q^n/p), p = e(z); refs Siegel 1961, Lang ch. 20) has log|f q^{v^2/2}| = (B2(r1)/2) log|q| + log|1 - q_z| + sum_n
log|(1 - q^n q_z)(1 - q^n/q_z)| = log|g_{(r1,r2)}(tau)|. (Direct derivation by Poisson summation in n: the m = 0 terms give 2 pi^2 y B2(r1),
each m != 0 gives one factor -2 pi log|1 - ...|.) The sum is even in omega, so the sign of the pairing does not matter.

**Step 4 (the character on the lattice).** Fix c = c_Q, b = c O_K, a = N b, and u. Scale: |g(a z_u; c)| = |g(z_u; c/a)|. For c/a:
A(c/a) = A(c)/a^2 = sqrt(p)·a/a^2 = sqrt(p)/a (A(O) = sqrt p and [O:c] = a). Put omega = nu/a, nu in c. Then
Im(conj(z_u) omega)/A(c/a) = Im(conj(z_u) nu)/sqrt p = Tr_{K/Q}( conj(z_u) nu/(2 sqrt -p) ), and A/|omega|^2 = sqrt(p)·a/N(nu).
For nu = x + y sqrt -p in O, with conj(z_u) = wbar - u sqrt(-p)/p and wbar = (1 - sqrt -p)/2, direct expansion gives
  Tr( conj(z_u) nu/(2 sqrt -p) ) = (y - x)/2 - u x/p,  Tr( wbar nu/(2 sqrt -p) ) = (y - x)/2.
So the phase is epsilon(nu) e(-u[nu]/p) with epsilon(nu) = (-1)^{x+y} = +1 iff nu in 2O_K (2O_K = {x + y sqrt -p : x = y mod 2}).
Extend the weight "epsilon(nu) on O, 0 off O" to all of O_K through O_K/2O_K = {0, 1, w, wbar} (O/2O_K = {0, 1}):
  **f(nu) := 1_P(nu) + 1_Pbar(nu) - 1**  has value 1 on 2O_K, -1 on 1 + 2O_K, and 0 on w + 2O_K, wbar + 2O_K (w in P, w not in Pbar),
which is exactly that weight. Since c = b ∩ O and (F2), with Phi_u(e, s) := sum'_{nu in e} e(-u[nu]/p) (N e/N nu)^s for e prime to q:
  **E(z_u, c/a; s) = p^{s/2} [ 2^{-s} Phi_u(bP, s) + 2^{-s} Phi_u(bPbar, s) - Phi_u(b, s) ].**
(N(bP) = 2a, so (sqrt p · a/N nu)^s = p^{s/2} 2^{-s} (N(bP)/N nu)^s on the bP part.)

**Step 5 (Gauss sums and the L-function).** Let G(eta) := sum_{y in F_p*} eta(y) e(y/p). For e prime to q, Phi_u = Phi_{-u} (nu -> -nu), so
  Psi(e, s) := sum_{u in F_p*/+-1} chi^2(u) Phi_u(e, s) = (1/2) sum'_{nu in e} [ sum_{u in F_p*} chi^2(u) e(-u[nu]/p) ] (N e/N nu)^s.
The bracket is chibar^2(-[nu]) G(chi^2) = chibar^2([nu]) G(chi^2) if [nu] != 0, and 0 if nu in q. For nu not in q, N(nu) = [nu]^2 (mod p)
(nubar = nu mod q), so chibar^2([nu]) = chibar(N nu) = chibar(N e) chibar(N d) where (nu) = e d, d integral, prime to q, in the class [e]^{-1}
of Cl(O_K); nu and -nu give the same d (O_K* = {+-1}, p > 3), cancelling the 1/2. Hence
  **Psi(e, s) = G(chi^2) chibar(N e) Z_{[e]^{-1}}(s),   Z_X(s) := sum_{d in X, d integral, (d, q) = 1} chibar(N d) N d^{-s}.**
Sum over Q with the weight chi(N b): chi(N b) Psi(bP, s) = G(chi^2) chibar(2) Z_{[bP]^{-1}}(s), and as b runs over Cl(O_K) once (Step 2c),
so do [bP]^{-1}, [bPbar]^{-1}, [b]^{-1}. With L_K(s, chibar o N) = sum_{d integral, (d,q)=1} chibar(N d) N d^{-s}:
  **S(s) := sum_Q chi(N b_Q) sum_u chi^2(u) E(z_u, c_Q/a_Q; s) = p^{s/2} (2^{1-s} chibar(2) - 1) G(chi^2) L_K(s, chibar o N).**
All of this holds for Re s > 1 (absolute convergence); both sides are entire (chibar o N is non-trivial), so it holds at s = 1.

**Step 6 (closing).** By Step 2(d) and Step 3, A_chi = sum_Q chi(N b) sum_u chi^2(u) · p · (-1/2 pi) E(z_u, c/a; 1) = -(p/2 pi) S(1):
  A_chi = (p^{3/2}/2 pi)(1 - chibar(2)) G(chi^2) L(1, chibar) L(1, chibar psi)   (L_K(s, chibar o N) = L(s, chibar) L(s, chibar psi)).
Classical evaluations (Sharifi, Iwasawa theory notes ch. 4, Thm 4.2.14, OPENED 2026-10-28; also opened by the referee), with
tau(phi) = sum_a phi(a) zeta^a: for even primitive phi mod p, L(1, phi) = -(tau(phi)/p) sum_a phibar(a) log|1 - zeta^a|; for odd primitive phi,
L(1, phi) = (pi i tau(phi)/p) B_{1, phibar}. With phi = chibar and phi = chibar psi:
  A_chi = -(i/2) p^{-1/2} (1 - chibar(2)) tau(chi^2) tau(chibar) tau(chibar psi) C_chi B_{1,chi psi}.
Hasse-Davenport product relation with m = 2 (Wikipedia, OPENED: "prod_{a mod m} tau(chi rho^a) = -chi^{-m}(m) tau(chi^m) prod_{a mod m} tau(rho^a)",
and tau(trivial) = -1): tau(chibar) tau(chibar psi) = chi(4) tau(chibar^2) tau(psi). Also tau(chi^2) tau(chibar^2) = chi^2(-1) p = p
(elementary: conj tau(eta) = eta(-1) tau(etabar) and |tau(eta)|^2 = p for eta != 1) and tau(psi) = i sqrt p for p = 3 mod 4 (Gauss; Wikipedia
"Gauss sum", OPENED by the referee). Therefore
  **A_chi = (p/2) chi(4)(1 - chibar(2)) B_{1,chi psi} C_chi = (p/2) chi(2)(chi(2) - 1) B_{1,chi psi} C_chi.** ∎
The L_K'(0) form in Theorem V3C is a restatement, not used elsewhere: L(0, chi psi) = -B_{1,chi psi} (Sharifi Prop 4.2.13 at n = 1, OPENED);
L(0, chi) = 0 for even chi != 1, so L_K'(0, chi o N) = L'(0, chi) L(0, chi psi); and L'(0, chi) = -C_chi/2 (Lerch: L'(0, chi) = sum_a chi(a)
log Gamma(a/p), plus the reflection formula; NOT OPENED; numerically consistent with check (d)).
