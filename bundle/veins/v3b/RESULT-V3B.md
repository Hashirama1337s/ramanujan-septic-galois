## 1. The p-th roots w_k = u_1^(k^2)/u_k (goal 1)

### Statement (proved on the page below; sufficiency direction)
Let p >= 5 be prime, m = (p-1)/2, u_j = 2 theta[j/p](i sqrt p)/theta[0](i sqrt p) (real, > 0), F_p as in C1.
**For integers n_1..n_m with sum_j n_j j^2 = 0 (mod p), the real number U = prod_j u_j^(n_j) lies in F_p.**
In particular w_k = u_1^(k^2)/u_k is in F_p for every k, and the group
E_R := <-1> x {prod u_j^(n_j) : sum n_j j^2 = 0 mod p} equals E_w = <-1, b_1, w_2, ..., w_m>. Proof (lattice generation): the exponent lattice {n in Z^m : sum n_j j^2 = 0 mod p} is generated by p e_1 (giving b_1 = u_1^p) and k^2 e_1 - e_k for 2 <= k <= m (giving w_k = u_1^(k^2)/u_k). Indeed, for such n, n - sum_{k>=2} (-n_k)(k^2 e_1 - e_k) = (n_1 + sum_{k>=2} n_k k^2) e_1 = (sum_j n_j j^2) e_1, and the coefficient is a multiple of p. Conversely each generator lies in the lattice.
For p = 7 mod 8 these are units (they are p-th roots of units).
Necessity (U not in F_p when sum n_j j^2 != 0 mod p): checked numerically only (null below, 26/26), not written out.

### Proof
Notation and facts exactly as proof/proof-C1-C3-v4.md §§1-3: a_j = ((p+2j)/2p, 1/2), a_0 = (1/2, 1/2), tau0 = sqrt -p,
O = Z[sqrt -p], M = H_O(zeta_p), F_p = M cap R. Sources: KSY10 = arXiv:1008.0473v2, **OPENED this run** (PDF text, Prop 2.2 and 2.4);
KSY25 = arXiv:2506.14139 (opened by the proof seat; Prop 5.1 and §4 as quoted in proof v4 §0).
1. *Modular function.* Put W := prod_j (2 theta[j/p]/theta[0])^(n_j), so U = W(tau0). By v4 Lemma 1,
   W = c · prod_j g_{a_j}^(n_j) · g_{a_0}^(-sum n_j), c = 2^(sum n_j) e^(-pi i sum n_j j/2p).
   KSY10 Prop 2.2(iii): g_r is in F_{12N^2} for r in (1/N)Z^2 - Z^2 and has no zeros or poles on H. With N = 2p:
   W is in F_{N''}, N'' = 48p^2, and W is finite and non-zero at tau0. So U lies in R := K_{O,N''} (KSY25 §4), and M is in R.
   By the triple product (v4 Lemma 2 item 1), W has a q^(1/2p)-expansion with **rational** coefficients.
2. *Kummer.* U^p = prod b_j^(n_j) lies in F_p, inside M. For sigma in Gal(R/M), sigma(U)^p = U^p, so sigma(U) = zeta_sigma U with zeta_sigma^p = 1.
3. *Reciprocity.* By KSY25 Prop 5.1, sigma = sigma_{g(x)}, g(x) = [t, -ps; s, t], x = t + s sqrt -p, d = t^2 + p s^2 prime to N''.
   sigma fixes zeta_p iff d = 1 (mod p); since d = t^2 (mod p), t = +-1 (mod p). Replacing x by -x (the class of -I acts trivially) gives t = 1 (mod p).
   Write g(x) = diag(1,d)·gamma, gamma in SL2(Z/N''), lift [A,B;C,D]: A = t, B = -ps, C = s/d, D = t/d (mod N''). So A = D = 1 (mod p), B = pB' with B' = -s.
4. *The transformation.* KSY10 Prop 2.4(ii): g_r o gamma = eps(gamma) g_{r gamma}, with eps(gamma) a 12th root of unity independent of r.
   The total exponent of the g's in W is sum n_j - sum n_j = 0, so eps(gamma) cancels: W o gamma = c · prod g_{a_j gamma}^(n_j) g_{a_0 gamma}^(-sum n_j).
   a_j gamma = a_j + S^(j), with S^(j) = ( ((p+2j)(A-1) + pC)/2p , ((p+2j)B' + D - 1)/2 ). Both are integers: the numerators are
   0 mod p (A = 1 mod p) and even (A + C = t + s = 1 mod 2, and B' + D - 1 = s + t - 1 = 0 mod 2, d odd). Same for j = 0.
   KSY10 Prop 2.4(iii): g_{r+S} = (-1)^(S1 S2 + S1 + S2) e^(-pi i (S1 r2 - S2 r1)) g_r. Here r2 = 1/2, so all factors are in mu_4 except
   e^(pi i S2 r1) with r1 = (p+2j)/2p, i.e. e^(pi i S2^(j)/2) · e^(pi i j S2^(j)/p). Now S2^(j) = S2^(0) + j B', so
   sum_j n_j j S2^(j) = S2^(0) · sum n_j j + B' · sum n_j j^2.
   - S2^(0) = (pB' + D - 1)/2 = 0 (mod p) because D = 1 (mod p), so the first term is a multiple of p.
   - sum n_j j^2 = 0 (mod p) by hypothesis, so the second term is a multiple of p.
   Hence W o gamma = Omega · W with Omega in mu_4. The action of diag(1,d) fixes W (rational coefficients) and sends the constant Omega
   to Omega^d, still in mu_4. In either composition order, W^{g(x)} = Omega' W with Omega' in mu_4.
5. *Conclusion.* sigma(U) = Omega' U with Omega' in mu_4, and also sigma(U) = zeta_sigma U with zeta_sigma in mu_p. As p is odd, sigma(U) = U.
   So U lies in M; U is real, so U lies in F_p. ∎
Remark (where the hypothesis enters): only B' = -s carries the sqrt -p direction of x. The p-power root of unity it produces is
e^(pi i B' sum n_j j^2/p), which is exactly the Kubert-Lang quadratic condition. For U = u_1 alone it is e^(-pi i s/p) != 1 for s != 0 mod p,
consistent with u_1 not being in F_p.

  - mod 2: it is ≡ (A-1) + C ≡ t + s - 1 ≡ 0 by (a), (c) and t + s odd.
  - So 2p divides the numerator.
- *Integrality of S_2^(j).* (p+2j)B' + D - 1 ≡ B' + D - 1 ≡ s + t - 1 ≡ 0 (mod 2) by (b), (d).
- *Key identities:*
  - S_2^(j) = S_2^(0) + jB', since (p+2j)B' = pB' + 2jB'.
  - S_2^(0) ≡ 0 (mod p): 2S_2^(0) = pB' + D - 1 ≡ D - 1 ≡ 0 (mod p) by (d), and p is odd. The parity of D plays no role.
- *Transformation.*
  - KSY10 2.4(ii) gives W∘γ̃ = c · ε^{Σ_j ν_j} · Π_j g_{a_jγ̃}^{ν_j}, and Σ_j ν_j = 0, so ε^0 = 1.
  - KSY10 2.4(iii) then gives W∘γ̃ = Ω·W with
    Ω = Π_j [(-1)^{S_1S_2+S_1+S_2} e^{-πi(S_1·(1/2) - S_2·(p+2j)/2p)}]^{ν_j} (S = S^(j)).
  - So Ω = ±exp(πiΦ), where Φ = Σ_j ν_j (-S_1^(j)/2 + S_2^(j)/2) + T and T := Σ_j ν_j j S_2^(j)/p.
- *T is an integer.*
  - pT = S_2^(0) Σ_j ν_j j + B' Σ_j ν_j j² = S_2^(0) Σ_{j>=1} n_j j + B' Σ_{j>=1} n_j j².
  - Both terms are multiples of p: the first by S_2^(0) ≡ 0 (mod p), the second by hypothesis.
  - So Φ ∈ (1/2)Z and **Ω ∈ μ_4**.

**Step 6 (rational coefficients), self-contained.**
*(a) v4 Lemma 1, verbatim* (proof/proof-C1-C3-v4.md lines 74-80):
> **Lemma 1.** For 1 ≤ k ≤ (p−1)/2 (so p ∤ k): u_k = 2θ[k/p](τ0)/θ[0](τ0) = 2e^{−πik/2p} g_{a_k}(τ0)/g_{a_0}(τ0), and b_k = B_k(τ0) with
> B_k = 2^p(−i)^k (g_{a_k}/g_{a_0})^p. The Siegel form also holds for every integer m with p ∤ m (with a_m := ((p+2m)/2p, 1/2)).

> g_{(a+½,½)} = −e^{πi(a/2−1/4)} q^{a²/2−1/24} Π(1+q^{n−1/2+a})(1+q^{n−1/2−a}).
> Taking the ratio of the a = m/p case to the a = 0 case gives θ[m/p]/θ[0] = e^{−πim/2p} g_{a_m}/g_{a_0}. ∎

The lemma is an identity of functions on H: the last line holds for every τ. Two consequences follow.
- With the definition of Step 0, W = c Π_{j≥0} g_{a_j}^{ν_j} = Π_{j≥1} (2θ[j/p]/θ[0])^{n_j} as functions on H.
  The constants e^{−πij/2p} and the factor 2 are collected in c, and the exponent of g_{a_0} is ν_0 = −Σ n_j.
- At τ0 = i√p this gives W(i√p) = Π u_j^{n_j} = U.

*(b) Rational q-expansion, proved here.* Put q = e^{2πiτ} and θ[a](τ) = Σ_{n∈Z} e^{πiτ(n+a)²} = Σ_n q^{(n+a)²/2}.
- For 1 <= j <= m, θ[j/p] = Σ_n q^{(pn+j)²/2p²} = q^{j²/2p²} · S_j, with S_j := Σ_n q^{n²/2 + nj/p}. S_j is a series in q^{1/2p} with every coefficient a non-negative integer.
  - Its exponents are n²/2 + nj/p. They are 0 at n = 0, and 1/2 − j/p > 0 at n = −1 (since j < p/2). Every other n gives a positive exponent.
  - So S_j = 1 + (strictly positive powers of q^{1/2p}): its constant term is 1, so S_j is a unit in Z[[q^{1/2p}]] and S_j^{-1} has integer coefficients.
- θ[0] = Σ_n q^{n²/2} = 1 + 2q^{1/2} + 2q^2 + …, constant term 1, so θ[0]^{-1} ∈ Z[[q^{1/2}]] ⊂ Z[[q^{1/2p}]].
- Therefore 2θ[j/p]/θ[0] = 2 q^{j²/2p²} · S_j · θ[0]^{-1}. Since n_j may be negative, use S_j^{n_j} for any integer n_j; this is legitimate because S_j is a unit.
- Hence W = 2^{Σn_j} · q^{Σ n_j j²/2p²} · Π_j S_j^{n_j} · θ[0]^{−Σn_j} = 2^{Σn_j} q^{ℓ/2p} · G, where:
  - Σ n_j j² = pℓ by hypothesis, so q^{ℓ/2p} is a power of q^{1/2p};
  - G ∈ Z[[q^{1/2p}]] with constant term 1.
- So W has a q^{1/2p}-expansion with **rational coefficients**: integers times 2^{Σn_j}. Since q^{1/2p} = (q^{1/N''})^{24p}, this is also a q^{1/N''}-expansion with rational coefficients, N'' = 48p².
  Products and quotients of such series with unit leading terms stay rational; that is all that was used.
- (Without the hypothesis the prefactor would be q^{Σ n_j j²/2p²}, a power of q^{1/2p²}. The coefficients would still be rational. The hypothesis is needed only in Step 5.)

*(c) Consequence.* KSY10 Prop 2.1 and KSY25 §4: diag(1,d) ∈ GL2(Z/N'') acts on F_{N''} through the Fourier coefficients, by ζ_{N''} ↦ ζ_{N''}^d.
All coefficients of W are rational, so **W^{diag(1,d)} = W**. This is the fact used in Step 6′.

**Step 6′ (the diagonal part).**
- diag(1,d) acts on Fourier coefficients by ζ_{N''} ↦ ζ_{N''}^d. W has rational coefficients, so W^{diag(1,d)} = W.
- Ω is a constant in Q(ζ_4) ⊂ Q(ζ_{N''}), so Ω^{diag(1,d)} = Ω^d.
- The action is a group action (KSY10 Prop 2.1), so:
  - (I) W^α = (W^{diag(1,d)})∘γ̃ = W∘γ̃ = ΩW;
  - (II) W^α = (W∘γ̃)^{diag(1,d)} = (ΩW)^{diag(1,d)} = Ω^d W.
- In both orders W^α = Ω'W with Ω' ∈ {Ω, Ω^d} ⊂ μ_4, since d is odd. No claim is made that Ω' = 1 at this stage.

**Step 7 (conclusion).**
- By KSY25 Prop 5.1, σ(U) = σ_α(W(τ_O)) = W^α(τ_O) = Ω'U.
- By Step 2, σ(U) = ζ_σ U. Since U ≠ 0, Ω' = ζ_σ ∈ μ_4 ∩ μ_p = {1}, because p is odd.
- So σ(U) = U for every σ ∈ Gal(R/M), and U ∈ M. U is a real number (all u_j > 0), so U ∈ M ∩ ℝ = F_p. ∎
